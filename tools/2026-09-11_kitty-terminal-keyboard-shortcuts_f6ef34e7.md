Kitty shortcuts, all `ctrl+shift` based:

**Tabs** — new `ctrl+shift+t`, close `ctrl+shift+q`, next `ctrl+shift+right`, prev `ctrl+shift+left`, next layout `ctrl+shift+l`, move tab fwd `ctrl+shift+.` / back `ctrl+shift+,`, set title `ctrl+shift+alt+t`

**Windows** — new `ctrl+shift+enter`, close `ctrl+shift+w`, next `]`, prev `[`, move fwd `f` / back `b`, resize `ctrl+shift+r`, focus specific `ctrl+shift+1..0`, new OS window `ctrl+shift+n`

**Copy/scrollback** — copy `ctrl+shift+c`, paste `ctrl+shift+v`, paste from selection `ctrl+shift+s`, scroll line up/down `ctrl+shift+up/down`, page `page_up/down`, top/bottom `home/end`, browse scrollback in less `ctrl+shift+h`, search scrollback `ctrl+shift+/`

**Appearance/misc** — font + `ctrl+shift+=` / − `ctrl+shift+-`, reset `ctrl+shift+backspace`, fullscreen `ctrl+shift+f11`, maximized `ctrl+shift+f10`, URL open `ctrl+shift+e`, unicode input `ctrl+shift+u`, terminal reset `ctrl+shift+delete`

**Config** — edit `ctrl+shift+f2`, reload `ctrl+shift+f5`, debug `ctrl+shift+f6`, help `ctrl+shift+f1`, command palette `ctrl+shift+f3`, kitty shell `ctrl+shift+escape`

All customizable in `~/.config/kitty/kitty.conf`.
